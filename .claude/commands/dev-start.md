Coroxy 개발 서버를 실행하고 시스템 프록시를 설정한다.

## 핵심 원칙

**프록시는 반드시 프로그램이 리스닝 중일 때만 켠다.** 프로그램 없이 프록시만 켜면 모든 트래픽이 실패한다.

## 실행 순서

1. **안전 정리**: 기존 시스템 프록시부터 먼저 끈다
   ```
   networksetup -setwebproxystate "Wi-Fi" off
   networksetup -setsecurewebproxystate "Wi-Fi" off
   ```
2. 기존 wails 프로세스와 점유 포트(8673, 8674, 5173, 34115) 정리
3. `wails dev` 백그라운드 실행
4. **포트 리스닝 확인**: `lsof -i :8673`으로 프록시 포트가 열릴 때까지 대기 (최대 30초, 2초 간격 폴링). 타임아웃되면 실패 처리 — **프록시를 켜지 않는다**
5. 포트가 열린 것을 확인한 후에만 시스템 프록시 설정:
   - HTTP 프록시: 127.0.0.1:8673
   - HTTPS 프록시: 127.0.0.1:8673
6. 사용자에게 프록시 ON 상태 알림
7. **감시 루프 시작** (백그라운드): wails 프로세스가 살아있는지 5초마다 확인. 프로세스가 죽으면 즉시 시스템 프록시를 해제하고 사용자에게 알린다

## wails 시작 실패 시

- 프록시를 절대 켜지 않는다
- 에러 로그를 사용자에게 보여준다
- 포트 충돌이면 해당 프로세스를 알려준다

## 주의

- 프록시 해제를 잊으면 인터넷이 안 되므로 반드시 해제할 것
- Wi-Fi가 아닌 다른 네트워크 서비스를 쓸 수 있으므로 `networksetup -listallnetworkservices`로 확인
